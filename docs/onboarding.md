# Onboarding

Rules for contributors and coding agents. If a change makes anything here false, update this file in the same change.

**Onboarding.** Fresh data directories show a two-screen introduction to the crew and approval flow, followed by a setup checklist on Home for nonblank profile notes, enabled and available agents in all three workflow seats, and a real (non-demo) job card. The sidebar's Getting started row shows compact setup progress on every page and links back to Home. Users can defer setup or explicitly finish it, reopen the setup checklist from Getting started in the sidebar, and reopen the introduction from Show introduction in the command palette or Settings > General. The introduction is a centred 600px clay sheet, and the setup checklist sits first on Home, above Needs you, with three 64px rows for the real criteria; its Finish setup is an outline button, because the page's glazed action belongs to Home's open Needs you row. Pipeline never shows the checklist; with no jobs it shows its own empty state. Versioned onboarding preferences live in `onboarding.json` in the data directory and synchronize through snapshots across browser/Electron; they do not change board events, role capabilities or approvals. Existing databases default to deferred onboarding on upgrade.

On Home the checklist's height is capped to the work area and it scrolls on its own, so its actions and Set up later stay reachable in short windows and phone landscape (568×320 and 320×480).
