## Remaining polish (none blocks shipping)

1. **Repeated advice inside Settings:** the unreadable message says "recover model choices in Settings > Runtimes" even when you are already there, right above the Recover button (`runtime-model-preferences/store.ts:24`). This message is shared with agent settings, where it is correct. Pass a context-free message to the dialog, or reword the callout there.
2. **Stacked buttons:** Open and Cancel are now inline, but these pairs still stack at different widths:
   - Retry sign-in / Recheck sign-in (`v2-claude-expired.png`)
   - Recheck installation / Retry installation (`v2-installation-failed.png`). Here the secondary button sits above the primary one, and the failure message comes after the action. Putting the message first, then Retry with Recheck beside it, would read better.
3. **Phone editor fields don't line up:** "Display name (optional)" wraps to two lines, so its input sits lower than Model selector (`phone-dark-models-custom-editor.png`). Stacking the two fields on narrow screens would fix it.
4. **Possible CLI call on window focus:** the preferences GET calls `service.runtimeModels(id)` on every focus or visibility change, in both `useRuntimeModels` and `useModelCatalog`. If that cached call re-runs native discovery once its 5-minute cache expires, refocusing the window can spawn a CLI model-list process. It is bounded and makes no inference request, but it is worth checking.
5. **Fixture text in screenshots:** "No installation found / Fictional installation is unavailable" appears next to an enabled Retry. Real detail strings may read differently, so I didn't count this as a defect.
