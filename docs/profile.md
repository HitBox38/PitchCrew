# Profile

Rules for contributors and coding agents. If a change makes anything here false, update this file in the same change.

**Profile.** User Markdown files under the data directory's profile folder. The Profile workspace uses shared paper textures, softly rounded sheets, sunken controls and raised clay selections. The page title sits in the compact workspace header without a separate page heading. The page fits the viewport with a keyboard-accessible folder tree with collapse/expand and search, closable, draggable tabs for open documents with per-note drafts, and the shared Markdown editor: a lazily loaded CodeMirror 6 surface with Obsidian-style live preview (marks hidden except on the focused caret's lines, drawn bullets and clay task boxes, hanging list indents, a Show Markdown syntax option, tables drawn as tables (also inside quotes and lists; a click opens the clicked cell's source) and fenced code behind a language chip), a formatting toolbar with pressed states and a narrow-width More menu, a "/" block menu that opens below the caret inside the editor (typing "/" near the bottom scrolls first; the note scrolls half a screen past its end), Markdown shortcuts, Tab between table cells (tables in quotes and lists keep their marks), a floating find/replace bar with match counts that becomes a two-row band above a narrow note, language-highlighted fenced code, per-document undo history, selection and scroll across tab switches (a newly opened note starts at its top), and Write | Split | Preview on one type scale with matching block positions (switching modes keeps the reader's place block by block in both directions, per note; Split's two columns follow each other by block, led by the one last touched, and Split is offered only on a sheet at least 40rem wide; Preview breaks lines exactly where Write does; Preview task boxes are linked to source tasks in one pass and only when the rendered and source task lists agree text for text; otherwise they stay read-only and the note says so). Notes autosave about a second after typing stops (a per-device option); every save names the copy it replaces, so a note changed elsewhere raises a conflict banner (Compare opens a numbered line diff; Use saved copy, Keep my draft) instead of being overwritten, and all writes from the page run one at a time; the daemon queues profile writes and rechecks run gating and any interrupted approved update when each one's turn comes. When the window leaves less than 26rem beside the explorer, the explorer opens as a drawer over the note (Escape, the scrim or choosing a note closes it, and widening the window keeps an open drawer as the column); on phones Insights and Sources show on the note list, not over an open note. The command palette and the explorer find notes by a plain search of their whole text (every word, not necessarily side by side), with the matching line highlighted; the palette lists notes before conversations, and opening a hit (or a cited quote) selects and marks the passage, while ⌘K on exactly that selection still opens the palette rather than linking it. Sources opens from the workspace header in a source-first dialog with a quiet list, an Add source action and provider choices in its empty state. Focused setup distinguishes GitHub note imports from project watches; agent proposals open in a focused review in the same dialog. Source rows expose explicit Watching switches, manual import reviews and a removal menu; action-specific loaders announce fetching and writes. Imports and applied proposals return to the list with success feedback and an explicit Open note action. The dialog fits its content and scrolls internally for longer lists or forms; existing import review drawers and account connection dialogs remain. See [docs/profile-sources-dialog.md](profile-sources-dialog.md). Only the notes, document and sources panels scroll; on mobile the explorer replaces the document until a note is selected. Markdown previews do not load remote images. Cmd/Ctrl+S saves while focus is in the note sheet or on the page; tab switching and drag reordering preserve drafts and the active note; whole-tab mouse/touch dragging uses the shared dnd-kit library with cancellation and reduced-motion support, and its preview stays level with the tabs and inside their visible strip, and Alt + left/right arrows reorder the focused tab without changing selection; closing edited notes and navigating away retain unsaved-change protection for all open drafts. Profile sources import nested GitHub folders (one pinned commit) or Google Drive folders (Docs, Markdown and plain text) through the existing read-only account connectors. Users review and select exact server-staged snapshots; import never re-fetches, and previews expire after ten minutes or restart. The import review sheet lists only added, changed, locally conflicting and removed-source documents, with filename/path search, compact shared accordion rows and paragraph/word diffs against the exact saved local text. Conflicts start unselected; unchanged documents stay hidden and bulk selection excludes both. Search preserves selection, and import actions stay pinned. Removed-source rows are informational and retain local copies, even for an entirely empty upstream folder. Per-source bounds are 100 documents, 30 folders, 50,000 characters per document and 1 million characters total. Imported source paths, links, revisions and content hashes live in profile-sources.json outside the repo. Maintenance proposals also persist exact reviewed documents, evidence and provenance in the board event log. Notes retain stable local filenames, with original paths and searchable labels in the UI. Imported nested paths form the default explorer hierarchy. Users can create empty and nested folders, open new notes in a selected folder, and move notes through a destination chooser. Folders can be renamed (with descendants) or deleted once empty. Notes rename on disk with their folder placement and imported-source records (`POST /api/profile/rename`); deletion moves them to `profile-trash/` in the data directory for 30 days with `POST /api/profile/restore` undo; both are blocked during active runs. Saves may send a SHA-256 `baseline` of the loaded content and receive 409 with the current text when the note changed on disk. Folder organization is saved atomically in profile-organization.json and synchronized in user snapshots across renderers. It organizes notes in the app without moving Markdown files on disk, changing source manifests, packet citations, board events or agent capabilities; explicit root placement overrides an imported path. Tree keyboard navigation uses arrows, Home/End and Enter/Space, and search reveals matching ancestors without changing collapsed preferences. Manual refresh flags locally edited notes and preserves removed upstream files; removing a source keeps its notes and account connection. Source imports grant no agent connector capabilities. Users may enable/pause watches or remove source connections during active runs; dedicated maintenance tools recheck the current watch and account after asynchronous reads. Profile note writes are serialized and blocked during active runs; workflows recheck the profile revision after asynchronous setup. Registered packet claims must be exact supported quotations. Mechanical lint is not a complete semantic fact checker.
