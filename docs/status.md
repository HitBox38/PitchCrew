# Feature status

Rules for contributors and coding agents. If a change makes anything here false, update this file in the same change.

default, live turn commentary and grouped tool activity, visible read-only agent DMs, local agent memory and user file attachments with AI Elements, persistent routines and scheduled actions managed by users and agents, an optional per-user background service that starts the production daemon at login, capability-gated batch pipeline reviews with every-seat assessments and user-approved targeted crew changes, shared and role-assigned Markdown skills with skills.sh imports and user-reviewed chat suggestions, bundled career skills and chat-based Career Coach, agent-triggered follow-ups without a per-chain count limit, user-approved role change proposals, watched profile maintenance proposals, optional seven-perspective deep resume reviews with automatic Writer corrections, scoped temporary CLI subagents, parent-controlled deadline extensions and saved before/after reports, source-backed Markdown packets with user-configurable packet rules and worker-bounded pattern checks, approval-gated local export, manual application tracking with user-reviewed bulk import of past applications from JSON/CSV exports or supported legacy SQLite trackers, user-only learning signals with Insights, tag merge and previewed stale-submission cleanup, chat-embedded local Chromium browsers with native Electron pages on desktop and streamed headless viewing on web, per-agent profiles, private manual takeover and supervised or bounded autonomous preparation, role-scoped read-only GitHub/Google Workspace connectors, capability-gated job discovery from user-saved public Greenhouse, Ashby, Lever, Comeet and Workable boards, capability-gated public posting link imports and existing-card refreshes by agents, and user-only Add job prefill from Greenhouse, Ashby, Lever, Comeet, Workable and SmartRecruiters posting links or structured public job pages, with an explicit Scout chat handoff for unsupported or unreadable public links. Browser posting imports convert simple accessibility headings, paragraphs and lists only against current inspected evidence, reject ambiguous conversion and remaining structural metadata before saving without dropping text, and leave snapshots and existing records unchanged. Other agent-extracted descriptions reject recognizable extraction syntax directly; manual descriptions are never automatically cleaned. Scout opens supplied posting links in the in-app browser when permitted and saves details against the current inspected page digest; new Scouts have supervised browser tools, while existing role permissions remain user-controlled. Demo is deterministic and available only with the daemon’s --dev flag; its example data also seeds a Waypoint job conversation showing finished turns, a waiting question, queued/paused/failed messages, crew follow-ups and pending role and skill proposals without starting runs; production seeds paused roles with role-specific recommended runtime/model/reasoning selected from the installed runtime checks and bounded model catalogs and preserves existing Demo roles as unavailable until the user selects a real runtime. Claude Code, Codex, Gemini CLI, OpenCode, GitHub Copilot CLI, Cursor Agent, Goose, Kiro CLI, Grok Build, Pi, oh-my-pi and Hermes Agent adapters are implemented; live provider runs are not part of automated verification. Automatic board discovery from other job sites, outreach, and whole-desktop control are deferred. Formatted and plain text PDF/DOCX packets, pre-draft application form inspection, user-confirmed field/file requirements and durable browser submission receipts are supported.
