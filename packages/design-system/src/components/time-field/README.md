# Time field

Adapted from Intent UI's shadcn registry components:

- [`@intentui/time-field`](https://intentui.com/r/time-field)
- [`DateInput` from `@intentui/date-field`](https://intentui.com/r/date-field)
- [Component documentation and demos](https://intentui.com/docs/components/date-and-time/time-field)

The React Aria composition and segment behavior are retained. Registry styling and its `field`/`primitive` helpers use Pitchcrew's existing `cn`, primitive layer and material tokens. The surrounding calendar and popover remain the app's shared shadcn/Base UI controls.
